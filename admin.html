  1. Open github.com/settings/personal-access-tokens/new (Fine-grained token)
  2. Under Repository access → Only select repositories → pick transfastglobal
  3. Under Permissions → Repository → Contents → set to Read and write
  4. Set an expiration, click Generate token, copy it, and paste above
